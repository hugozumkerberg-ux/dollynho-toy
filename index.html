🟦 LINHAS 1 A 22: ESP32-S3 DevKit
• Encaixe a placa centralizada no canal divisor central (linhas 1 a 22).
• LED On-Board RGB (GPIO 48): ATIVADO!
  💚 3 piscadas verdes: Wi-Fi conectado com sucesso.
  💙 1 piscada azul: Resposta da API IA Gemini OK.
• Linha 1 (Esquerda): Pino 3V3 ➔ Fio Vermelho para o trilho (+).
• Linha 3 (Esquerda): GPIO 4 ➔ Jumper para Linha 33 (LED Verde).
• Linha 5 (Esquerda): GPIO 6 ➔ Jumper para Linha 38 (LED Vermelho).
• Linha 7 (Esquerda): GPIO 15 ➔ Jumper para Linha 50 (Buzzer +).
• Linha 11 (Esquerda): GPIO 8 (SDA) ➔ Jumper Azul para Linha 29.
• Linha 14 (Esquerda): GPIO 9 (SCL) ➔ Jumper Amarelo para Linha 28.
• Linha 21 (Esquerda): GND ➔ Fio Preto para o trilho (-).
• Linha 4 (Direita): GPIO 1 ➔ Jumper Roxo para Linha 45 (Potenciômetro).
📟 LINHAS 26 A 29: Tela OLED SSD1306
• Encaixe o módulo OLED de 4 pinos nas colunas b, c ou d:
• Linha 26: Pino VCC ➔ Fio Vermelho para trilho (+) (3.3V).
• Linha 27: Pino GND ➔ Fio Preto para trilho (-) (GND).
• Linha 28: Pino SCL ➔ Conectado à Linha 14 (GPIO 9 SCL).
• Linha 29: Pino SDA ➔ Conectado à Linha 11 (GPIO 8 SDA).
🟢 LINHAS 33 A 35: LED Verde (Alta B3 / Feliz)
• Linha 33: Resistor 220Ω (da Linha 33 até Linha 34).
• Linha 33: Jumper vindo da Linha 3 (GPIO 4).
• Linha 34: Perna longa do LED Verde (+ Ânodo).
• Linha 35: Perna curta do LED (- Cátodo) ➔ Fio Preto para trilho (-).
🔴 LINHAS 38 A 40: LED Vermelho (Queda B3 / Triste)
• Linha 38: Resistor 220Ω (da Linha 38 até Linha 39).
• Linha 38: Jumper vindo da Linha 5 (GPIO 6).
• Linha 39: Perna longa do LED Vermelho (+ Ânodo).
• Linha 40: Perna curta do LED (- Cátodo) ➔ Fio Preto para trilho (-).
🎛️ LINHAS 44 A 46: Potenciômetro (Ajuste Brilho)
• Linha 44: Terminal 1 ➔ Fio Vermelho para trilho (+) (3.3V).
• Linha 45: Terminal Central (Cursor) ➔ Fio Roxo para Linha 4 (GPIO 1).
• Linha 46: Terminal 3 ➔ Fio Preto para trilho (-) (GND).
🔊 LINHAS 50 A 52: Buzzer Piezoelétrico
• Linha 50: Terminal Positivo (+) ➔ Fio Branco para Linha 7 (GPIO 15).
• Linha 52: Terminal Negativo (-) ➔ Fio Preto para trilho (-) (GND).
• Linhas 53 a 60: Espaço livre para expansão (microfone I2S ou servos!).
